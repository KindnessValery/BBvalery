# PROSALES Landing Platform

Полноценная production-ready платформа для продажи цифровых и физических продуктов с поддержкой VSL (Video Sales Letter) и TSL (Text Sales Letter). 

## Особенности проекта

- **Data-Driven архитектура**: добавление новых статей и продуктов без изменения компонентов.
- **Адаптивность**: полностью responsive дизайн от 320px мобильных устройств до десктопа.
- **Современный стек**: React, TypeScript, Tailwind CSS, Vite, React Router.
- **Удобная работа**: легко открывается и редактируется в VS Code.

## Как начать работу локально

### Шаг 1. Установка Node.js
Убедитесь, что у вас установлен Node.js (рекомендуется версия 18 или выше). Скачать можно с [официального сайта](https://nodejs.org/).

### Шаг 2. Установка зависимостей
Откройте папку проекта в VS Code или терминале и выполните:
```bash
npm install
# или
pnpm install
```

### Шаг 3. Запуск сервера разработки
Для локального запуска выполните:
```bash
npm run dev
# или
pnpm run dev
```
Сайт будет доступен по локальному адресу (обычно `http://localhost:5173`).

### Шаг 4. Сборка для Production
Когда вы будете готовы опубликовать сайт:
```bash
npm run build
# или
pnpm run build
```
Собранные файлы появятся в папке `dist/`. Их можно загрузить на любой хостинг (Vercel, Netlify, обычный сервер).

## Как управлять контентом

### Как добавить новую статью (VSL или TSL)
1. Откройте файл `src/data/articles.ts`.
2. Скопируйте существующий объект внутри массива `articles` и вставьте его.
3. Измените `id`, `title`, `description`, `type` ("VSL" или "TSL"), `category` и остальные поля.
4. Новая статья автоматически появится на главной странице.

### Как добавить новый товар / изменить цены
1. Откройте файл `src/data/products.ts`.
2. В массиве `products` вы можете изменить цену, название вариантов (`variants`) и основное изображение. 
3. Форма покупки автоматически пересчитает цены на основе этих данных.

### Как заменить изображения
1. Поместите ваши изображения в папку `public/images/...` (например, `public/images/vsl/my-image.webp`).
2. В файлах данных (`articles.ts` или `products.ts`) укажите путь к файлу: `"/images/vsl/my-image.webp"`.
3. Картинки обновятся автоматически на всем сайте.

### Как заменить видео
В файле `src/data/articles.ts` найдите нужную статью и измените блок `video`:
```ts
video: {
  type: 'youtube', // Возможные значения: 'youtube', 'vimeo', 'mp4'
  url: 'https://www.youtube.com/watch?v=YOUR_ID'
}
```

## Структура компонентов

- `src/components/Header` — Навигация и адаптивное меню.
- `src/components/PurchaseForm` — Главная форма покупки с расчетом цены.
- `src/components/VideoPlayer` — Компонент для воспроизведения видео.
- `src/components/ImageGallery` — Галерея изображений для страницы продукта.
- `src/pages/Home.tsx` — Главная страница со списком всех статей.
- `src/pages/ArticlePage.tsx` — Динамическая страница для каждой статьи.
